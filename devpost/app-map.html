Proof Before Done: code map

Follow one real action across the project. Open source files in an editor to inspect each step.

1. Enter a claim and select a file

index.html provides the form controls #claim, #evidenceFile, #checkType and #expected.

2. Click Run

src/app.js handles #runCheck and passes the current inputs to ProofLogic.verifyFile(...).

3. Determine a named result

src/checker.js checks exactly one condition, computes an optional fingerprint, and always leaves overall acceptance as REVIEW REQUIRED.

4. Render and export

src/app.js renders observations as plain text and exports JSON or Markdown. src/checker.js escapes HTML in Markdown receipts.

Try it yourself

In the app, use correct-deliverable.txt with DELIVERABLE READY. Then change expected text to SHIP APPROVED and run again. Watch the criterion change without ever granting overall acceptance.
